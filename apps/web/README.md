# Pro-Flow Career OS Web

The isolated Next.js shell for the guided Pro-Flow Career OS experience.

Phase 2 uses validated neutral fixtures only. It does not read personal data,
write Pro-Flow profile files, call AI providers, or execute portal tools.

## Commands

```powershell
npm install
npm run dev
npm run lint
npm test
npm run typecheck
npm run build
```

The app consumes shared contracts from `../../packages/career-core`.
